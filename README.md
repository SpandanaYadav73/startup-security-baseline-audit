# Startup Security Baseline Audit Framework

A reusable security baseline audit framework for small startups.

## Project Overview

This project develops a practical and repeatable security health-check
framework using free and community security tools.

The assessment covers:

- Network Exposure
- Transport Security
- Web Application Security
- Identity & Access
- Cloud / Storage Misconfiguration

## Lab Environment

- Ubuntu 24.04.1 LTS
- WSL2
- Docker
- Docker Compose
- Nmap
- DVWA

## Frameworks

- CIS Controls v8
- NIST Cybersecurity Framework
